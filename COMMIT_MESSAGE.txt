feat: integrate ML prediction model with all improvements

This PR integrates a machine learning model into the FPL RAG system for predicting player performance in upcoming gameweeks. All 5 improvement remarks from the milestone_1 notebook have been implemented and tested.

## Improvements Implemented

### 1. Temporal Train/Test Split (Most Impactful)
- Prevents data leakage by training on past data and testing on future data
- Split: 72% train (Aug 2023 - May 2025), 8% val, 20% test (Oct 2025 - Mar 2026)
- Implementation: `FPLModelTrainer.temporal_train_test_split()`

### 2. Remove/Lag Features (Data Leakage Prevention)
- Removed `total_points` and `bps` from feature set (target-derived)
- Created lagged target `upcoming` = next gameweek's total_points
- Use 4-game rolling average as `form` feature
- Implementation: `FeatureEngineer.engineer_features(lag_features=['total_points'])`

### 3. Add Dropout to Neural Network
- Added Dropout layers (0.3, 0.2, 0.1) after Dense layers
- Reduces overfitting in baseline NN model
- Implementation: `FPLModelTrainer.train_neural_network()`

### 4. Fix Position Labels
- Fixed "Forwards (MID)" → "Midfielders (MID)"
- Created POSITION_NAMES mapping dictionary
- Implementation: `FPLModelTrainer.POSITION_NAMES`

### 5. Rename nn_bad_model → nn_baseline_model
- Improved naming throughout codebase
- Better communicates purpose as baseline

## Model Performance

Trained on 3 recent seasons (79,683 records):
- **RMSE**: 1.94 (test set)
- **MAE**: 1.02 (test set) 
- **R²**: 0.324 (test set)
- **Features**: 103 (after one-hot encoding)

Model predicts within ~1 point on average, with consistent performance across train/val/test splits (no overfitting).
